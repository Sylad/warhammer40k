Sur la page d'une faction, chaque carte de chapitre porte dans un petit médaillon le portrait de son primarque. Ce portrait venait d'une recherche libre sur le wiki, qui se trompait parfois de personnage : les Iron Hands ont pu montrer Fulgrim, les Imperial Fists un char.

Le médaillon reprend maintenant l'image de la fiche du primarque lui-même : Ferrus Manus pour les Iron Hands, Rogal Dorn pour les Imperial Fists, et ainsi pour chaque chapitre. Quand le wiki ne renvoie pas une image sûre de ce primarque, le médaillon n'apparaît pas, plutôt qu'un portrait faux ; la carte nomme toujours le primarque. Pour un lecteur d'écran, l'image s'annonce « Portrait de » suivi du nom du primarque.
