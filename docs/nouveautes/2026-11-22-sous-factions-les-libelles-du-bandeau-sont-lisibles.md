Sur la page d'un chapitre, d'un régiment ou d'une dynastie, les petites étiquettes du bandeau (« Primarque », « Monde-mère », « Fondation », « Devise ») se perdaient dans l'image quand celle-ci était claire : gris sur gris, elles devenaient presque illisibles.

Elles reposent maintenant sur un encart sombre, qui garde la lecture nette quelle que soit l'image, sur téléphone comme sur ordinateur. Une sous-faction qui n'a aucune de ces informations n'affiche pas d'encart du tout, plutôt qu'un cadre vide.
