# Audit des liens du site — 2026-10-02 (L39)

Consigne : « il y a potentiellement des liens morts ». Inventaire mesuré de tous les liens du
codex, correction de chaque lien interne cassé, liens externes corrigés quand le remplacement est
certain, garde automatique contre les régressions.

## Méthode et outils (`frontend/scripts/`)

| Outil | Ce qu'il fait | Réseau |
|---|---|---|
| `npm run liens` (`liens.mjs`, `liens-lib.mjs`) | inventaire statique : gabarits Angular (`routerLink`, `[routerLink]`, `href`, `fragment`), code (`route:`, `routerLink: [...]`, `router.navigate`), données d'amorçage `backend/seed/*.json` (16 références entre données rendues en lien), zones de la carte galactique ; vérification des liens internes | aucun |
| `scripts/liens.test.mjs` (Vitest, CI « Contrôles frontend ») | rejoue la vérification interne ; échoue sur tout lien interne cassé | aucun |
| `npm run liens:crawl` (`liens-crawl.mjs`) | parcours de l'application en marche (backend :3001, `ng serve` :4201) depuis `/` + toutes les adresses de l'inventaire et toutes les fiches ; Chromium, liens lus sur les directives `RouterLink` (`window.ng`), requêtes externes coupées, `/api/wiki-image` bouchonné | local seulement |
| `npm run liens:externes` (`liens-externes.mjs`) | liens externes : 2 requêtes simultanées, 1,5 s par hôte, une reprise, délai 15 s, agent de navigateur ; Fandom par l'API MediaWiki (50 titres par requête), YouTube par oEmbed ; `--wiki` résout les requêtes d'image du wiki | oui, à la demande |

Règles vérifiées pour un lien interne : une route de `app.routes.ts` sert l'adresse (sinon la
route `**` renvoie **en silence** vers /factions) ; l'identifiant existe dans les données
(sinon la fiche reste sur « Chargement… ») ; l'ancre existe sur la page cible ; pas d'ancre nue
`href="#x"` sans gestionnaire (avec `<base href="/">`, le navigateur va à `/#x`, l'accueil — vérifié
au clic) ; le fichier existe, casse comprise (prod sous Linux) ; chaque unité a sa fiche technique.
